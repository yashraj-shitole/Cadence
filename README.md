# Cadence

A small, private daily habit tracker, to-do list and notes app. No build step, no dependencies, no account — everything is stored in your browser's localStorage.

## Run

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Features

- **Habits** – daily check-in, current streak, 7-day history (click a past day to fix it).
- **To-do** – due dates, priority, All/Open/Done filters, overdue highlighting.
- **Notes** – search, autosave, newest first.
- **Export / Import** – JSON backup, since data lives only in this browser.
