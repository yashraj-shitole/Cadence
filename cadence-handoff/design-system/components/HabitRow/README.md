One habit: its check, cue, minimum version, last seven days and streak.

**You provide:** title, cue, minimum, seven day-states (done, minimum, rest, missed, today) and the streak count.

- The cue line is the habit's trigger in the user's own words ("After chai, on the balcony"). It is always shown: a habit tied to a cue forms faster than one tied to a clock time.
- "Minimum: 1 page" is always visible, so a low-energy day has an obvious way to still count.
- **Week dots:** filled = done, tinted ring = minimum, clay ring = rest day, small grey dot = missed, dashed ring = today and still open. Each state has its own shape, so none depends on hue. A missed day is never red and never an X.
- **Streak** is a plain number with "day streak". A rest day and a minimum day both keep it. A miss does not zero it in view: the row then shows "Best 31" and a new count, without any alert.
- A done row keeps its place until the next app open; it does not jump to the bottom mid-scroll.
- Tap the row for Habit detail. Tap the check to log. Long-press the check for "Did the minimum".
