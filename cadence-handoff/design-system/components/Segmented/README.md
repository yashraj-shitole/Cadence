A two-to-four option switch with a sliding thumb.

**You provide:** the option labels and the selected index.

- Used for Quick add type (Task, Habit, Note), theme (Light, Dark, Auto) and week start.
- For on/off use Toggle; for more than four options use a list.
- Place it on glass (a sheet or a settings card), never on bare backdrop: its unselected labels are `ink-muted`.
- **Motion:** the thumb slides with `ease-in-out` over `duration-base`. **Haptic:** `haptic-tick` as it lands.
- Unselected labels are `ink-muted` on the `track`; in high-contrast themes the thumb gains a 2px `accent` border.
